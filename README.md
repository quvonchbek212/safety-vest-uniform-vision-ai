# 🦺 PPE Safety Vest & Uniform Compliance Vision AI

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://python.org)
[![YOLO](https://img.shields.io/badge/Ensemble-PersonGate%20%2B%20Forma-green.svg)](models/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Dual-model ensemble system designed to verify worker safety uniforms and high-visibility reflective stripes.

## 🌟 Key Capabilities

* **Dual-Model Fusion:** Dedicated PersonGate detector paired with YOLO Forma classifier.
* **Reflective Stripe Validation:** Checks strict geometric containment of high-visibility stripes on worker bodies.
* **Live Dashboard:** Provides real-time counts of compliant vs non-compliant personnel.

## 🚀 Quickstart

```bash
git clone https://github.com/quvonchbek212/safety-vest-uniform-vision-ai.git
cd safety-vest-uniform-vision-ai
pip install -r requirements.txt
python app.py
```
